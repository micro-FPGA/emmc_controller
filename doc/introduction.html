eMMC Controller

Description

The eMMC Controller IP provides a host-side interface between an SoC's system bus and an external eMMC device over a 1/4/8-bit MMC interface. It implements the JEDEC JESD84-B51A standard and manages command sequencing and data transfers.

Devices Supported

LAV-AT, LFCPNX, LFD2NX, LIFCL, LFMXO5
